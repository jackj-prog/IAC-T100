# IACT100 Digital Checklist

A digital version of IAC's **T100 Pre-Test / Inspection checklist** (document
QAP07_04_17) for the test department. One HTML app, no installation, no
server, works offline — and prints back out as the original paper form.

## Using it

**On a PC:** open `index.html` in any browser. A copy on the shared drive or
a bench PC desktop is enough.

**On a phone/tablet:** the app needs to be reachable at a web address once
(after that it works offline):

1. Merge this branch and enable **GitHub Pages** on the repository
   (Settings → Pages → Deploy from branch → your default branch, root).
   The app is then at `https://<owner>.github.io/IAC-T100/`.
2. Open that address on the phone and choose **Add to Home Screen**
   (Safari: Share → Add to Home Screen; Chrome: menu → Add to Home screen /
   Install app). It installs with the IAC T100 icon, opens full-screen, and
   the service worker keeps it working with no signal in the workshop.

Any internal web server works just as well as GitHub Pages — the app is
static files.

### Workflow

1. Fill in the **job header**: customer, contract number, items covered,
   date, tester name and initials. Your initials are stamped automatically
   against every item you mark.
2. Work through the four parts (tabs, mirroring the paper form):
   Pre-Test / Inspection · Routine Tests EN60204/EN61439 ·
   Functional Test / Validation · Final Inspection.
3. Each item: **✓ checked**, **N/A** or **✗ snag**, plus a comment box
   usable on passing items too (test values, document references, etc.).
   Rows 3.7.1–3.7.5 are write-in rows; 4.13 takes the Director's
   early-release approval.
4. **Sign off each part** — it warns if items are still unmarked.
5. **Print / PDF** regenerates the record as the original T100 document
   (Times New Roman, boxed tables, sign-off lines, document number) and
   opens the print dialog — print it, or choose "Save as PDF" for the job
   file. Printing an empty checklist produces a blank form, so it also
   replaces the paper master.

**Backup / Open** save and load the raw record as a `.json` file — for
archiving with the job or moving a half-finished checklist between devices.
Progress autosaves on the device (localStorage); it does not sync between
devices on its own.

## Maintenance

- Checklist content lives in the `CHECKLIST` array near the top of the
  `<script>` block in `index.html`, transcribed 1:1 from QAP07_04_17. If the
  controlled document is revised, edit the array and update `DOC_REF`.
- The printed form is generated by `buildPrintDoc()` in the same file; its
  layout styles are under the `@media print` block.
- `sw.js` caches the app for offline use. When you ship a change, bump the
  `CACHE` version string in `sw.js` so phones pick up the new version.
- An Excel (.xlsx) exporter existed up to commit `047d89b` and was removed
  in favour of the printed form — recoverable from git history if the
  department ever wants it back.
